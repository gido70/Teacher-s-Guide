# دليل المعلم — حصتك التفاعلية بلا تعقيد

**إعداد وتنفيذ: عبد الرحمن عوض الكريم (أبو هيثم)** — © 2026 جميع الحقوق محفوظة. انظر [LICENSE.md](LICENSE.md).

موقع عربي مجاني للمعلم يتكون من جزأين:

1. **خطوات البدء**: كيف يثبّت المعلم ClassPoint في PowerPoint، ويشغّل أول سؤال تفاعلي، ويُدخل طلابه، ويحل المشكلات الشائعة.
2. **المُعِدّ**: أداة تحوّل نص الدرس، أو ملف PDF أو Word، أو صور صفحات الكتاب وأوراق الامتحانات، إلى أسئلة مراجَعة. يصدّر منها:
   - عرض PowerPoint عربي، وفي ملاحظات كل شريحة اسم زر التفاعل وعدد الخيارات والإجابة الصحيحة.
   - امتحانًا للطباعة (مع نموذج ثانٍ بترتيب مختلف عند الحاجة) ومفتاح تصحيح.
   - ملف مشروع `.teachers-guide.json` للحفظ والمشاركة.

> دليل المعلم مشروع مستقل، وليس تابعًا لـ ClassPoint (Inknoe) ولا Microsoft ولا OpenAI، ولا معتمدًا منها.

## ما الذي يحدث داخل المُعِدّ؟

- **PDF وWord ‏(docx) والنصوص**: يُستخرج نصها داخل المتصفح (pdf.js وmammoth).
- **الصور وملفات PDF المصوّرة**: لا تُقرأ محليًا. يضيف الطلب تعليمات للذكاء الاصطناعي ليقرأها بنفسه عند إرفاقها، ويعيد نصها في `source_text` لمطابقة الشواهد.
- **وضعان**: «أنشئ أسئلة جديدة» و«حوّل أسئلة موجودة عندي».
- **أنواع الأسئلة**: اختيار من متعدد، وصح أو خطأ، وملء الفراغ، وإجابة قصيرة، وسحابة كلمات.
- **التحقق من الشاهد**: يطبّع النص العربي (التشكيل والهمزات والتاء المربوطة والأرقام) ثم يطابقه مع المادة. ينبّه المعلم ولا يرفض الاستيراد.
- **الاستيراد المرن**: يقبل الرد كاملًا مع الكلام قبل JSON وبعده، والفواصل الزائدة، وصيغ الإجابة المختلفة.
- **الحفظ**: تلقائي في `localStorage` على جهاز المعلم فقط.
- **تنبيه الخطة المجانية**: يظهر إذا تجاوز العرض ٥ أسئلة تفاعلية.

لا توجد خدمة خلفية ولا مفتاح API، ولا تُرسل الملفات إلى أي خادم.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (مثلًا `teachers-guide`) وارفع **محتويات** هذا المجلد إلى جذره.
2. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح الموقع على `https://<اسم-المستخدم>.github.io/teachers-guide/`.

الملف `.nojekyll` موجود في الحزمة. **انتبه:** بعض واجهات الرفع تخفي الملفات التي تبدأ بنقطة، فتأكد من رفعه.

## التشغيل محليًا

افتح `index.html` في Chrome أو Edge. لاستخراج نص PDF بأفضل أداء، شغّل خادمًا محليًا بسيطًا:

```
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## إضافة نموذج جاهز

أضف عنصرًا إلى `assets/templates-data.js` بالبنية نفسها. اجعل كل `evidence` مقتطفًا حرفيًا من `source`، فتظهر علامة «الشاهد مطابق».

## تطبيق على الهاتف (PWA)

يُثبَّت الموقع على الهاتف كتطبيق بشعاره، ويعمل بدون إنترنت بعد أول زيارة.

- **Android (Chrome):** يظهر زر «ثبّت التطبيق» أعلى الصفحة، أو من قائمة المتصفح ⋮ ← «تثبيت التطبيق».
- **iPhone (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **عند تحديث أي ملف في الموقع:** غيّر رقم `VERSION` في أول ملف `sw.js` (مثلًا `tg-v2`)، حتى تصل النسخة الجديدة للأجهزة المثبّت عليها التطبيق.
- يعمل التثبيت على رابط `https` فقط (GitHub Pages يوفره تلقائيًا)، ولا يعمل عند فتح الملفات من الجهاز مباشرة.
